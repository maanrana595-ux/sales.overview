# sales.overview
Power BI Sales Overview Dashboard analyzing sales, qty, profit, and performance by region using interactive visualizations and DAX

## About the Project

This is a Power BI sales dashboard built to look at sales performance across four regions: Central, East, South, and West.

The report lets the user select a year and switch between Sales, Profit, and Quantity. Each region has a monthly view, and the report also compares the selected year with the previous year.

## What the Dashboard Shows

- Sales, Profit, and Quantity by region
- Monthly sales for Central, East, South, and West
- Previous year sales for comparison
- Sales by state using a map
- Sales by state using a bar chart
- Current Year (CY), Previous Year (PY), and YoY figures
- Year selection from 2021 to 2024
- A metric selection for Sales, Profit, and Quantity

## Main Report Sections

### Regional Sales

The left side of the report shows monthly performance for each region. The selected metric changes when Sales, Profit, or Quantity is selected.

### Sales by State

The map shows where sales are coming from across the United States. The bar chart next to it gives a simple comparison of sales between states.

### Current Year vs Previous Year

The table at the bottom compares:

- CY Sales
- PY Sales
- YoY Sales
- CY Profit
- PY Profit
- YoY Profit
- CY Quantity
- PY Quantity
- YoY Quantity
